# Concept frames

One key frame per film concept, rendered as 1600×900 stills to compare looks before choosing a direction.
Everything here is procedural stand-in art (no real client work yet).

| # | Concept | Frame |
|---|---|---|
| 01 | Ek Pankhudi | the marigold opens; the camera chooses one petal |
| 02 | Do Aangan | the spark leaves Jaipur (night Earth, gold thread) |
| 03 | Mehendi Mein Naam | the hidden names, found |
| 04 | Parat Dar Parat | the invitation comes apart into its layers |
| 05 | Kaagaz Se Aage | the gold foil lifts off a printed card |
| 06 | Do Baar Khola | through the glass, inside the chat |

Render: `npm install && node render.mjs` (or `node render.mjs 04-parat-dar-parat`). Output goes to `out/`.
